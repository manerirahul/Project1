   POWER BI - POWER QUERY (M) SCRIPTS
   Pizza Sales Analytics warehouse (PostgreSQL)
   ------------------------------------------------------------
   HOW TO USE
   1. Power BI Desktop > Home > Transform data > Advanced Editor
   2. New blank query for each block below, paste, rename the query
      to the name in the comment header.
   3. Set the two parameters first (Home > Manage Parameters):
        PG_Server   Text   e.g. aws-0-eu-central-1.pooler.supabase.com:5432
        PG_Database Text   postgres
   4. Credentials: Database, user postgres.<project_ref>, your password,
      Encryption = enabled (Supabase requires SSL).
   5. Storage mode: Import (fastest, refresh on a schedule).
   ============================================================ */
